# منظور صناعي — MVP

موقع عربي تعريفي حديث للهندسة الصناعية والنظم، مع صفحة متخصصة في تقاطع ISE مع الذكاء الاصطناعي وعلوم البيانات.

## التشغيل

الموقع ثابت ولا يحتاج إلى بناء. افتح `index.html` مباشرة، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الصفحات

- `index.html`: التعريف بالتخصص ومساراته وأثره.
- `ai-data.html`: ISE × AI & Data Science، التطبيقات ومسار التعلم.

## خط ثمانية

ملفات الويب الرسمية مضمنة داخل `assets/fonts/`:

- `thmanyahsans-Regular.woff2`
- `thmanyahsans-Medium.woff2`
- `thmanyahsans-Bold.woff2`
- `thmanyahserifdisplay-Bold.woff2`
- `thmanyahseriftext-Regular.woff2`

يستخدم الموقع «ثمانية الرقمي» للواجهة، و«ثمانية للنصوص» للفقرات التحريرية، و«ثمانية للعناوين» للعناوين الكبيرة. فُعّلت خصائص OpenType `salt` و`swsh` للعناوين المختارة لإظهار الحروف المرسلة، مع استخدام الكشيدة بصورة تحريرية محدودة.

يستخدم الموقع `assets/manthoor-logo.png` في الواجهة لضمان التوافق مع الاستضافة الثابتة، مع الاحتفاظ بنسخة SVG الأصلية داخل مجلد الأصول.
